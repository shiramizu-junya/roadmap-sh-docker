# 01. 用語集（逆引き）

Docker の用語を、**出会った順ではなく引きたい順**に並べた表。

- **骨格は P0-3 で作る。** この時点では空欄でよい
- 以降のステップで `N-0. このステップの初出トークン` に出た用語を、**そのステップの生成時に1行ずつ追記する**
- 「1行の意味」は、その用語を知らない人に**1文で**言える形にする。説明が2文以上必要なら、それは仕組み解剖に置くべき内容
- 「詳しい解説」列には教材内の位置（例: `p2-dockerfile.md P2-2`）を書く。**同じ説明を2回書かない**ための索引
