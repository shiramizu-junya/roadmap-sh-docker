# 01. 用語集（逆引き）

**この表は、あなたが自分の言葉で埋める。** AI が書いた説明を読むのではなく、**自分で書いたものだけが残る**（`docs/00-plan.md` §4 の P0 設計メモ）。

**埋め方**

1. 「🧒 かみくだくと」の列を、**専門用語を使わずに**埋める。身近なものへのたとえでよい
2. 「1行の意味」は、その言葉を知らない人に**1文で**言える形にする
3. 書けない行があったら、「詳しい解説」の場所を読み返してから書く
4. 以降のステップで新しい言葉が出るたびに、**その回のうちに1行足す**
