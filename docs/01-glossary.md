# 01. 用語の逆引き

「自分の言葉」の列は読者が埋めます。読み返して使える形で書いてください。

| 用語 | 正式名称 | 🧒 かみくだくと | 定義 | 初出 | 自分の言葉 |
| --- | --- | --- | --- | --- | --- |
| コンテナ | container | 箱を開けて生活を始めた部屋 | イメージから起動した、隔離されたプロセス | P0-1 | |
| イメージ | container image | 封をした段ボール | アプリと実行に要るものをまとめた、コンテナの元 | P0-1 | |
| 共有ライブラリ | shared library | みんなの道具箱 | 複数のプログラムが共通で使う部品 | P0-1 | |
| カーネル | kernel | パソコンの管理人 | アプリの要求を受けて機械を動かす、OS の中心部分 | P0-2 | |
| VM | virtual machine | ソフトだけのパソコン | 機械を仮想的に作り、その上で別の OS を動かす仕組み | P0-2 | |
| ベアメタル | bare metal | 本物の機械 | 仮想化をしない物理マシン | P0-2 | |
| ホスト | host | コンテナが住む建物 | 本教材では、コンテナのすぐ外側の Linux VM | P0-2 | |
| ゲスト | guest | 建物に入る側 | ホストの上で動く側 | P0-2 | |
| デーモン | daemon | 頼まれるのを待つ裏方 | 裏で動き続けるプログラム。Docker では `dockerd` | P0-3 | |
| レジストリ | container registry | 配送センター | イメージを保管して配るサービス | P0-3 | |
| OCI | Open Container Initiative | 段ボールの規格の団体 | イメージと実行方法の標準を定める団体 | P0-3 | |
| containerd | containerd | コンテナの管理係 | コンテナの一生を管理するランタイム | P0-3 | |
| runc | runc | コンテナの組み立て係 | OCI の仕様に沿ってコンテナを作る低レベルランタイム | P0-3 | |
